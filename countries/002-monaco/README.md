# 第002国：摩纳哥（Monaco）

> 面积约2.08平方公里（包含新近填海土地），世界第2小。本文根据此前摩纳哥详解整理，按土地文化史、国家制度史和现代经济史分层。共同背景参见[基督教与罗马帝国](../../03-基督教与罗马帝国.md)。

## 第一章：地理决定了怎样的历史？

摩纳哥位于地中海北岸，陆地被法国包围，邻近意大利边界。它属于法国里维埃拉与利古里亚海岸的交汇地带。山区紧靠大海，平坦腹地极少，海湾、岩石高地和山地通道长期决定交通与军事活动。

摩纳哥岩（Le Rocher）俯瞰赫拉克勒斯港，是适合建立堡垒的岩石高地。中世纪以前，地形有助于瞭望与防御；但耕地稀少，面对大国难以单靠军事长期独立。摩纳哥以后必须依赖海上贸易、外交联盟、财政收入和周边市场。

地理关键地点：摩纳哥岩、赫拉克勒斯港、热那亚、马赛、里米尼之外的利古里亚海岸、芒通与罗克布吕讷、附近罗马奥古斯都纪念碑所在地拉蒂尔比。

## 第二章：史前摩纳哥为什么已有古人类活动？

境内天文台洞穴（Grotte de l'Observatoire）于1916年前后因工程活动发现史前遗存。考古研究发现石器、动物遗骸和多个时期人类活动地层。部分较早地层被认为属于约35万—40万年前的人类活动证据量级，涉及阿舍利文化传统的石器技术。

阿舍利文化是考古学根据石器技术建立的分类，并非一个可直接识别的现代民族。手斧、石片和石核表明制造者具有工具加工经验，但不能推断其语言、宗教和今天的国家身份。

冰期海平面与现代不同，洞穴位置相对于当时的海岸可能有变化。发现数十万年前遗迹不代表同一个人口共同体连续居住至今。

## 第三章：利古里亚人、希腊人和摩纳哥名称

古代希腊与罗马文献提及的利古里亚人（Ligures），是分布在今意大利西北及法国东南部分地区的多种地方人群，并非一个统一现代国家。其语言与内部文化差异仍有不确定性。

约公元前600年，福西亚希腊人在今日马赛建立马萨利亚（Massalia），成为西地中海重要贸易中心。摩纳哥所在海岸受其航海网络影响，古代的 Monoikos/Monoïkos 名称与希腊文化记忆有关。

赫拉克勒斯（Heracles，罗马文化中常称 Hercules）是古希腊神话英雄。摩纳哥的赫拉克勒斯港与其崇拜及名称传统联系紧密；“独居的赫拉克勒斯”是著名词源解释，但也有学者提出利古里亚语言或地方名称来源，不能当作没有争议的唯一结论。

## 第四章：罗马时代与基督教传播

公元前2世纪前后罗马逐渐控制法国南部、意大利西北部相关地区。摩纳哥海岸被纳入罗马军事、道路、港口和行政网络。

邻近法国拉蒂尔比的奥古斯都战胜纪念碑约建于公元前7至前6年，纪念罗马在阿尔卑斯地区的征服。它不在今天摩纳哥境内，却说明山地交通与帝国统治的联系。

罗马带来拉丁语言、道路、法律与宗教变化。后来的基督教传播于罗马世界，逐渐成为当地重要宗教。西罗马体制瓦解后，文化并没有立即中断，拉丁语言渐变成地方罗曼语。

## 第五章：热那亚为什么与摩纳哥王朝有关？

中世纪意大利不是统一国家，而是由公国、城市共和国和教会领地等组成。热那亚是重要海上共和国，商人家族依靠贸易、金融和军事力量参与政治。

圭尔夫派与吉伯林派最初与教宗和皇帝的政治竞争有关，但也牵涉城市权力和家族利益。格里马尔迪家族属于热那亚政治世界，与圭尔夫派相关。

1215年，热那亚势力在摩纳哥岩上修建堡垒。1297年1月8日，传统叙述称弗朗索瓦·格里马尔迪假扮方济各会修士进入城堡，随后夺取堡垒。今天国徽中的持剑修士纪念这段传统。

**1297年不是现代独立连续开始的证明。** 此后控制权仍有争夺，14世纪家族统治逐渐稳固。家族还获得芒通与罗克布吕讷等周边地区，当时的摩纳哥领土比今天大得多。

## 第六章：西班牙、法国与王朝生存

16世纪，摩纳哥开始受到西班牙哈布斯堡势力保护；但外来驻军也可能限制地方统治者自主权。1641年，奥诺雷二世通过《佩罗讷条约》转向法国保护体系。

法国大革命于1789年爆发。1793年，法国共和国吞并摩纳哥，格里马尔迪家族失去统治权；当地一度以赫丘利堡（Fort-Hercule）称呼。1814年后独立地位逐渐恢复。**不能称摩纳哥自1297年至今完全没有独立中断。**

1815年维也纳会议后，摩纳哥又处于撒丁王国保护下。1848年革命波及芒通和罗克布吕讷，两地脱离摩纳哥统治并寻求撒丁方面保护。

1861年，摩纳哥与法国签订条约，正式放弃两地权利，法国承认其主权并作出财政安排。失去的领土通常估计约占原有领土80%。原有农业土地和税源损失，迫使摩纳哥寻求新的经济模式。

## 第七章：赌场为何成了国家经济转折点？

查理三世（Charles III）于1856年成为亲王，面对严重财政困境。摩纳哥利用法律制度差异和优美海岸环境，吸引欧洲富裕阶层旅游消费。

1863年，在弗朗索瓦·布朗等人的经营下，赌场与相关企业逐渐形成制度化发展。豪华酒店、餐饮、歌剧、花园与高端服务，使蒙特卡洛（Monte-Carlo）成为综合度假中心，而非只有赌博场所。

1866年，该城区正式获得“蒙特卡洛”名称。1868年铁路交通改善，连接尼斯和意大利方向，客源明显扩大。1869年摩纳哥废除多项直接税。

**蒙特卡洛是摩纳哥境内城区，不是另一个国家；摩纳哥城（Monaco-Ville）则是摩纳哥岩上的历史城区。**

1879年蒙特卡洛歌剧院开幕，建筑与巴黎歌剧院设计师加尼叶有关。摩纳哥形成王室宫廷、意法文化、欧洲音乐艺术和国际旅游相结合的都市文化。

## 第八章：海洋科学为什么成为摩纳哥文化的一部分？

阿尔贝一世（Albert I，1848—1922）热衷海洋调查，组织和资助科学考察，推动海洋测量、生物与环境研究。1910年摩纳哥海洋博物馆开馆，位于摩纳哥岩的临海一侧。

海洋对摩纳哥的文化意义不断变化：史前时期是生态资源，古希腊与罗马时期是交通通道，中世纪是商业和防御空间，19世纪成为旅游景观，近现代又成为科学研究及生态保护对象。

## 第九章：20世纪战争与外交

1918年，法国与摩纳哥签订条约：法国保障摩纳哥独立、主权和领土完整，但摩纳哥行使主权时须考虑法国的重要政治、军事和经济利益。

二战时期，摩纳哥先后受到意大利及德国军事占领。1942年8月27—28日夜间，摩纳哥当局在外部压力下参与逮捕和移交部分犹太人，受害者中有人被送往纳粹集中营和灭绝营。2015年，阿尔贝二世公开为战争期间摩纳哥当局参与迫害犹太人的行为道歉，并主持纪念活动。

1956年，美国好莱坞演员格蕾丝·凯利嫁给兰尼埃三世，婚礼经电视媒体全球传播，推动摩纳哥王室与现代明星文化结合。她婚后参与慈善与文化活动，1982年因车祸去世；国家现代化不能全部归因于这场婚姻。

1962年，法国总统戴高乐政府与摩纳哥在税收、传媒和双边权力问题上发生严重冲突，法国加强边境海关检查。1963年新税收协定使大多数法国公民不能仅凭迁居摩纳哥就自动免缴法国个人所得税；特定历史居住者有例外。1962年摩纳哥也颁布新宪法。

## 第十章：F1、现代社会与国家身份

1929年第一届摩纳哥汽车大奖赛举办；1950年世界一级方程式锦标赛首届赛事包含摩纳哥站。城市街道、狭窄弯道、隧道与港口构成高辨识度赛道。赛事不仅是体育比赛，也是旅游、传媒、王室仪式和国际品牌传播的结合。

现代摩纳哥为世袭君主立宪制。2005年阿尔贝二世继承王位。其政府与议会、司法机关共同运作，但亲王仍拥有较强政治权力。1993年加入联合国，2004年加入欧洲委员会。2002年与法国签订更新双边关系的新条约，并于2006年生效。

摩纳哥富有高净值居民，却并非所有人都是富豪。大量劳动者从法国和意大利跨境通勤。经济有旅游、金融、专业服务、建筑和贸易等，不只有赌场。

一般个人居民不缴纳个人所得税，但存在增值税、特定企业税、遗产和其他相关税收；法国公民还受到1963年协定约束。低税制的收益需要与住房、监管、财政可持续性等问题一并分析。

## 第十一章：语言、信仰与新土地

官方语言为法语。本土摩纳哥语（Monégasque）与利古里亚语传统密切相关，既不同于标准法语，也不能简单等同于现代意大利语。现代教育支持摩纳哥语传承；英语、意大利语也广泛使用。

圣德沃特节（1月27日前后）将当地殉道者传说与航海、焚烧小船仪式联系起来。11月19日是国庆日，融合王室与公共仪式。

由于土地极少，摩纳哥利用高密度建筑、地下空间和填海扩大城市空间。丰维耶于20世纪70年代开始填海建设；2024年12月启用Mareterra海上扩建区，新增约6公顷土地。工程增加空间，也引发珊瑚、沉积物、水流和生态影响方面的争论。

## 第十二章：文化史应该如何计算？

| 层次 | 参考起点 | 含义 |
|---|---|---|
| 史前人类活动 | 约35万—40万年前 | 考古地层和石器，不代表连续同一民族 |
| 古代利古里亚与希腊联系 | 公元前第一千纪 | 地中海地方文化、港口贸易、赫拉克勒斯传统 |
| 罗马文化 | 公元前2世纪后 | 道路、法律、语言和宗教影响 |
| 中世纪热那亚与格里马尔迪 | 1215年、1297年、14世纪 | 堡垒及家族统治逐渐形成 |
| 现代独立和领土安排 | 1861年 | 对法关系、失去芒通和罗克布吕讷 |
| 现代旅游都市 | 1863年以后 | 赌场、铁路、酒店、文化和服务经济 |

**结论**：摩纳哥土地最古老可考人类活动约35万—40万年；较清晰可追溯的地中海地方文化约2500—3000年；格里马尔迪王朝从1297年传统起算约729年，但它并非1297年至今连续独立。
