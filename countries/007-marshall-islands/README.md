# 第007国：马绍尔群岛（Marshall Islands）

> 面积约181平方公里，世界第7小；29个环礁与5座独立珊瑚岛。2021年人口普查为42,418人。此前长篇讲解的结构化归档。共有知识：[人类起源](../../01-人类共同起点.md)、[跨国海洋与殖民史](../../04-跨国共同历史.md)。

## 导入：在核试验以前，这里已经有丰富的文化

马绍尔群岛是密克罗尼西亚的海洋社会。居民发展了传统远洋航海、木枝波浪导航图、母系亲族、土地权利和酋长制度。

1946—1958年，美国在比基尼与埃尼威托克环礁进行了67次核试验，强制迁居和放射性沉降物使社区、环境与健康遭受长久影响。2026年，国际社会仍在讨论受害者补救、数据公开和历史责任。

但不能用核试验完全定义马绍尔群岛。必须先认识那些在殖民和核时代以前已经存在的文化。

## 第一章：地理、岛链与居住条件

马绍尔群岛位于太平洋中西部、赤道以北。29个环礁和5座独立岛屿的总陆地面积约181平方公里；每个环礁又可能由许多分散小岛及中央潟湖组成。全国陆地面积极小，海洋空间却非常广阔，不同环礁之间可能相距数百公里。

主要分为西部 Ralik（日落）和东部 Ratak（日出）两条岛链，名称体现太阳方位与传统地理认识。

首都在马朱罗（Majuro）环礁。比基尼（Bikini）与埃尼威托克（Enewetak）是主要核试验区；朗格拉普（Rongelap）和乌特里克（Utirik）遭严重放射性沉降；夸贾林（Kwajalein）是二战战场和后来美国导弹测试相关基地所在环礁；埃贝耶（Ebeye）是人口密度较高的居民区。

环礁低平、淡水资源有限、土地薄弱，居民长期依赖海洋、椰子、露兜树、面包果和地方生态知识。

## 第二章：最早定居与南岛语言

马绍尔群岛最早定居一般估计在距今约2000年的量级，但最初航路、人员来源及岛群定居顺序并无完全确定的单一结论。

马绍尔语属于南岛语族中的密克罗尼西亚语言分支。南岛语族是一组有共同语言祖先的语言，不是一个统一民族或一支从台湾直接驶向所有太平洋岛屿的军队。史前迁徙和人群交流历时漫长。

岛上没有形成古罗马式城市帝国，并不意味着缺乏复杂社会。这里对土地、海洋、亲族、资源和航海风险发展出不同的专门制度。

## 第三章：海浪为什么可以导航？

远方风暴形成的涌浪能够跨越很长海域。波浪遇到岛礁或浅水地形会发生反射、折射和交互作用。对没有受训练的人，海面可能只是看似相同的起伏；而经验丰富的航海者能观察不同波列、风向、星辰、海鸟及船体摇晃，并结合出发前记忆判断航路。

马绍尔传统木枝航海图（stick charts）通常使用植物茎条、纤维和贝壳制作。其中不同结构表示波浪、岛屿及其相互关系。

**Mattang**：偏向教学的海浪原理示意模型，不一定直接对应真实地理图。

**Meddo**：表示特定岛群之间位置与波浪特征的知识图。

**Rebbelib**：覆盖范围更广的岛屿关系与航海知识图。

这些并非现代比例尺地图，也通常不是出海后随时像GPS那样查阅的工具。传统航海者主要在出发前学习、记忆，并凭航行中的感知和经验判断。

它们是一套高度发达的地方经验知识体系，部分现象可以通过现代海洋物理学解释，却不等于古代航海者已经写出现代流体力学方程。

19世纪殖民航运、20世纪战争和人口迁徙使传承受到压力。马朱罗的 Waan Aelōñ in Majel（WAM）等组织今天通过传统造舟、航海训练和青年教育支持文化恢复。文化保护不仅是博物馆收藏，更包括让知识继续被使用。

## 第四章：母系亲族与传统土地权利

马绍尔传统社会的重要组织原则之一是母系继嗣，某些身份和土地权利通过母系亲族传递。但母系并不等于女性掌握全部政治权力；传统酋长和等级制度中也有男性领导职位。

Bwij 和 Jowi 是理解亲族与身份的重要马绍尔文化概念。家庭、亲族身份、土地使用权、劳动责任与酋长权威相互关联。

传统土地制度常区分：

- **Iroij / Iroijlaplap**：首领，具有较高习惯政治与土地权威。
- **Alap**：具体亲族或土地事务负责人。
- **Ri Jerbal**：按习惯享有相应劳动和使用权利、同时承担义务的人。

权利与义务随岛屿及历史条件变化，不能把首领简单等同于拥有无限处置权的现代私人地主。2023年有关习惯土地继承的法律仍承认这些身份及母系继嗣的重要性。

为什么核试验迁居对文化影响如此严重？因为祖先土地不仅是地产，还与亲族地位、劳动、食物、墓地和地方共同体记忆有关。失去土地不等于只损失一处可用货币替代的住房。

## 第五章：食物、编织与 Jaki-ed

传统食物来源包括鱼类、贝类、椰子、露兜树、面包果、芋类和其他本地资源。岛民发展了储存露兜树果实、制绳、编织、建舟及海洋资源使用技术。

Jaki-ed 是传统精细编织席的重要形式，历史上可用于服饰与具有社会意义的仪式。纤维处理、图案设计和织法具有很高技术与文化价值。

进口布料、战争、人口变化曾使相关技艺传承减少。2006年前后开始的地方文化恢复项目，参考博物馆历史馆藏，重建技术传承和师徒教学。现代恢复的作品可能与两百年前不完全相同，仍属于有生命力的当地文化。

## 第六章：欧洲记录、椰干贸易和传教

16世纪已有欧洲航海者目击相关岛屿；1788年英国船长 John Marshall 与 Thomas Gilbert 航经此地，后来的英文群岛名称与 Marshall 相关。但英文名称不意味着欧洲人第一次发现无人居住的岛屿。

19世纪，椰干（copra）贸易快速发展。椰干可加工成椰子油，用于肥皂、食品和其他工业商品。传统食物资源进入全球商品网络，居民获得现金和外来商品，也可能依赖外部商人的价格、船舶与信用体系。

1857年前后，来自美国及其他太平洋地区的公理宗相关传教网络开始较系统传播基督教，发展读写教育与教会机构。当地马绍尔人后来也成为牧师与教会领导者，宗教传播不是完全单向的欧洲行动。基督教成为今天重要文化组成部分，但早于它的航海和亲族制度不能被抹去。

## 第七章：1885年德国与1914年日本殖民统治

1885年，马绍尔群岛被德国纳入太平洋殖民保护地体系。外来贸易企业及行政机构控制椰干贸易和部分政治安排；传统酋长体系没有完全消失，而是在殖民治理中被重新安排。

1914年第一次世界大战爆发后，日本占领德国太平洋据点；1920年国际联盟确认日本管理部分原德国太平洋殖民地，马绍尔群岛成为日本委任统治地区之一。

日本时期推广日语教育、商业和基础设施，之后日益军事化。委任统治不等于当地居民拥有现代独立主权。

## 第八章：1944年为什么成为太平洋战争战场？

1930年代日本在部分环礁加强军事设施，准备防卫太平洋中部据点。1944年，美军为向西推进，在夸贾林和埃尼威托克等地发动登陆作战。

岛屿很小，但宽阔潟湖、机场和港口对军队、飞机和舰船具有战略价值。作战造成军人死亡、建筑破坏和当地居民生活困难。

二战结束后，美国继续保持军事存在，并将部分环礁用于核武器试验。

## 第九章：为什么美国在1946年选择比基尼？

1945年广岛和长崎原子弹爆炸后，美国希望研究核武器对舰艇、设备、人员和建筑的影响，并进一步开发威力更大的核装置。

马绍尔群岛在战争后由美国实际控制，1947年成为联合国战略托管地的一部分，军事地位特殊。试验规划者认为偏远环礁适合布置舰船并限制人员进入，但试验区是当地人的祖辈家园。

1946年3月7日，比基尼环礁167名居民在美国军方安排下离开。最初迁往朗格里克（Rongerik）等地，却因食物、水源和环境限制反复迁移，后来又到基利岛等地生活。

所谓“临时搬离”并没有按居民原先理解的方式迅速结束。亲族土地权、捕鱼习惯和文化环境遭到长期改变。

## 第十章：十字路口行动与核试验发展

1946年7月1日，Able试验在空中引爆核装置；7月25日，Baker试验在水下引爆。美国在比基尼潟湖布置舰船测试核爆影响，水下爆炸卷起含放射性物质的海水和沉积物，造成复杂污染。

此后美苏冷战与核军备竞赛升级。1949年苏联成功试爆原子弹，美国加快发展热核武器。1952年在埃尼威托克进行 Ivy Mike 热核试验；1954年在比基尼进行 Castle Bravo。

**总数：1946—1958年67次核试验，其中比基尼23次、埃尼威托克44次。** 这是核试验数量，不应与爆炸当量或受害人数混用。

## 第十一章：1954年Castle Bravo造成什么灾难？

1954年3月1日，美国在比基尼引爆 Castle Bravo 热核装置，实际爆炸当量约1500万吨TNT，约为广岛1945年原子弹约1.5万吨TNT当量的1000倍；这比较的是能量，不是伤亡倍数。

爆炸威力高于原本预测，并卷起珊瑚、土壤及沉积物，放射性沉降物被风带到远处。

朗格拉普、乌特里克等环礁居民没有预先全部撤离。有人看到被称作“白色雪花”的污染沉降物，随后出现皮肤损伤、脱发、恶心等相关症状。美国随后撤离部分受影响居民。

需要区分爆炸直接冲击、外部辐射和通过饮水食物摄入放射性物质。碘-131半衰期约8天，可在甲状腺富集；铯-137半衰期约30年，可在环境中持续更久。不同环礁居民受到的剂量不同，群体健康风险与某位患者具体疾病归因也不能混淆。

日本渔船“第五福龙丸”当时在周边海域，23名船员遭到放射性沉降暴露，引发日本社会重大反核运动及食品安全讨论。该船员死亡与具体医学因素之间仍有研究争议，不宜简单归结为同一医学机制。

## 第十二章：为什么“比基尼”又成了泳装名称？

1946年7月5日，法国设计师 Louis Réard 推出名为 bikini 的两件式泳装，名称借用了前几天比基尼环礁原子弹试验新闻的轰动效果。

对全球商业文化，bikini后来常表示泳装和海滩；对比基尼环礁居民，它首先是祖先家园和被迫迁移的历史记忆。同一个名字在不同文化语境中可以有完全不同的意义。

## 第十三章：1970年代为什么有人回迁又再次撤离？

核爆停止不等于环境风险立即消失。部分比基尼居民在1970年代回迁，后来发现居民体内铯-137水平等问题严重，1978年再次撤离。朗格拉普居民也经历过回迁与再度迁移。

一个地方的外部辐射剂量相对较低，不代表长期食用当地农作物和饮水就一定安全。评估还需要关注食物链、土壤、地下水和个人行为。居民充分知情和参与决策是环境恢复的重要条件。

## 第十四章：鲁尼特穹顶是否会造成进一步污染？

埃尼威托克环礁的鲁尼特岛（Runit）有一座大型混凝土覆盖结构，俗称 Runit Dome。20世纪70年代，美国将部分受到核污染的土壤和废弃物集中到核试验形成的弹坑内并覆盖。

它不是在所有方向均建有现代完全防渗隔离层的容器，底部与原有珊瑚地质环境相联系，因此地下水、海水和沉积物迁移长期受到关注。

对穹顶的讨论必须分开三个问题：混凝土结构有无损坏、污染物是否迁移、这种迁移是否显著增加居民辐射风险。

美国能源部开展视觉检查和放射化学监测，2026年又发布有关检查资料。美国政府部分评估认为穹顶内物质相对于周边既有污染产生的额外风险可能有限；马绍尔政府强调海平面变化与长期责任。这些观点需要结合测量、时间跨度和不同风险情景评价。不能说穹顶已被确认马上崩塌，也不能因此否认过去核试验的历史责任。

## 第十五章：核索赔与赔偿争议

1986年自由联系协定及配套核索赔安排生效，美国提供了1.5亿美元的核索赔专项基金等援助机制。

马绍尔核索赔法庭随后对个人伤害、财产损失等作出大量裁定，但基金规模不足以足额支付全部裁定。2026年联合国人权机构相关讨论提及核索赔法庭累计评定金额超过23亿美元。

美国强调1980年代协议已构成特定索赔争端的最终安排，且已提供不同援助；马绍尔方面则认为健康、环境、文化和代际伤害未获得充分补救。

**2024—2043年自由联系经济援助总额约23亿美元，与核索赔法庭评定的逾23亿美元不是同一笔钱。** 不可因数字相近，就误称所有核试验赔偿已经履行。

赔偿不仅涉及金额，还包括健康服务、环境修复、数据公开、受害者参与及跨代权利。

## 第十六章：1979、1986和1991年为何都是重要日期？

1947年，美国取得联合国太平洋岛屿战略托管地管理权，马绍尔群岛属于其一部分。去殖民化运动和民族自决要求促成新的政治制度。

1979年5月1日，马绍尔群岛宪法生效，建立以 Nitijela（国会）为核心的自治政府。总统由民选国会议员选出，兼任国家元首和政府首脑；传统酋长的地位也在国家制度中得到一定体现。

1986年10月21日，《自由联系协定》（COFA）生效，马绍尔群岛获得独立主权地位，与美国建立特殊防务、财政和人口流动关系。

1990年相关联合国托管安排终止；1991年9月17日，马绍尔群岛加入联合国。

这三个日期分别对应自治宪法、自由联系与独立、联合国成员地位，不是同一事件。

## 第十七章：自由联系制度和美国军事基地

自由联系不等于马绍尔群岛成为美国州或海外领地。它保有自己的宪法、政府和外交关系；美国承担特殊防务责任，保持某些军事活动权利，并提供长期财政支持。

夸贾林环礁有美国的里根弹道导弹防御试验场等军事设施，广阔海域适合测试雷达及相关飞行系统。居民集中在埃贝耶等岛屿，住房、供水、卫生和就业机会分配存在压力。军事现代化与地方居民福利并不自动同步。

符合条件的马绍尔公民可依据自由联系协定在美国居住和工作，但这不会自动让他们成为美国公民。2021年人口普查为42,418人，较2011年约5.3万明显减少，外移是重要因素。美国阿肯色州等地有较大的马绍尔侨民社区。

人口外移能够提供汇款、学习和医疗机会，也可能影响本土劳动力、学校和传统文化传承。

## 第十八章：2024—2026年的长期合作与国际责任

美国与马绍尔群岛更新自由联系经济合作，2024年相关美国立法安排了2024—2043财年合计约23亿美元的长期支持，涉及公共财政、信托基金和不同项目，但不能直接当作核试验全部索赔的清偿。

截至2026年11月，马绍尔群岛总统为希尔达·海妮（Hilda C. Heine），她2016年首次当选，2024年再次就任，属于太平洋具有重要历史意义的女性领导者之一。

2026年联合国人权机构继续讨论核试验遗产、健康、土地、环境、资料公开及有效补救，并推动有关技术协助与能力建设。数据主权——当地居民与国家能否掌握影响自己健康、土地和法律诉求的数据——成为重要议题。

## 第十九章：海平面与核污染为何交织？

马朱罗等环礁地势低矮，受到高潮位淹水、海岸侵蚀、淡水透镜体盐化和基础设施威胁。NASA 2024年资料指出马朱罗在过去约30年海平面上升约10厘米，并对未来约30年上升约19厘米作出预测。预测随情景和模型调整，并非已经发生的实测数字。

部分历史核污染地点也位于海岸、地下水和沉积物环境中。气候风险与核试验责任并非同一种问题，但可能在具体地点相互影响。

岛屿面积变化不能等同于居住安全；科学监测、文化土地权与居民参与必须结合。

## 第二十章：国家节日怎样体现多层身份？

3月1日的核试验幸存者纪念日，提醒人们1954年Castle Bravo等试验造成的伤害。

5月1日宪法日纪念1979年自治宪法生效。

Manit Day强调传统文化、航海、语言、手工艺和社会记忆。

一座国家可以同时珍惜早于殖民的文化、追求核试验受害者公正，并发展现代民主制度，不需要被其中某一段历史完全定义。

## 第二十一章：时间轴与文化史长度

| 时间 | 事件 |
|---|---|
| 约2000年前 | 太平洋居民逐步定居 |
| 16—18世纪 | 欧洲早期航海接触与后来英文名称形成 |
| 1857年前后 | 基督教传教活动扩大 |
| 1885—1914 | 德国殖民保护地 |
| 1914—1944 | 日本占领、委任统治与军事化 |
| 1944 | 美军在夸贾林等地登陆 |
| 1946 | 比基尼居民迁离、十字路口核试验 |
| 1946—1958 | 美国67次核试验 |
| 1954-03-01 | Castle Bravo及严重放射性沉降 |
| 1970年代 | 部分居民回迁后再次撤离 |
| 1979 | 共和国宪法生效 |
| 1986 | 自由联系协定生效，主权独立 |
| 1991 | 加入联合国 |
| 2024 | 新自由联系经济安排相关立法 |
| 2026 | 联合国继续讨论核试验人权与赔偿问题 |

**文化史估计约2000年**，不能用1986年独立或1946年核试验作为当地文化开端。
