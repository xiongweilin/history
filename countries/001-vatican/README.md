# 第001国：梵蒂冈（Vatican City）

> 面积约0.44平方公里，世界最小的主权国家。本篇为**根据当前可确认的前文讨论主题所作的重建版**，并非此前梵蒂冈长篇问答的逐字导出。共同背景参见根目录[《基督教与罗马帝国》](../../03-基督教与罗马帝国.md)、[《六大早期文明区域》](../../02-六大早期文明区域.md)。

## 导入：世界最小的国家，为什么具有世界性影响？

梵蒂冈城国位于意大利首都罗马之中，陆地面积不足半平方公里。它拥有自己的法律、国旗、行政制度、邮政与部分公共设施，但其意义并不取决于土地多寡，而是与全球天主教会的中央治理体系密切相关。

它既不是古罗马帝国的最后一块领土，也不是耶稣在公元1世纪建立的现代微型国家。现代梵蒂冈城国创建于**1929年**，但罗马基督教社群和教宗制度的历史远远更久。

阅读时请一直区分四个对象：**基督教**是一种世界性宗教传统；**天主教会**是其中一大宗派体系；**教廷**是教宗与中央治理机构代表的宗教国际法主体；**梵蒂冈城国**是1929年建立、用于保障教廷独立的领土国家。

## 第一章：梵蒂冈这片土地在基督教之前是什么？

今天圣彼得广场、教堂和博物馆所在的区域，在古代属于罗马城西侧的梵蒂冈山与台地附近。罗马时代这里有道路、园林、墓地和相关建筑，并不是从一开始就只有教堂。

古罗马城在公元前数百年逐渐扩张为控制意大利及地中海广大地区的重要政权。罗马共和国传统起点为公元前509年；公元前27年前后，奥古斯都建立元首制，通常被视为罗马帝国的政治制度开端。

罗马既是军事和政治中心，也是多种宗教交汇的大城市。早期存在罗马诸神、希腊传统及东方地中海宗教活动。基督教当时尚不存在，因此不能把整座古罗马城的史前和古典时代都算作基督教文化本身。

## 第二章：基督教是怎样产生的？

耶稣生活在公元1世纪罗马帝国统治下的犹太地区，活动背景属于犹太宗教与社会世界。犹太教在此之前已形成悠久的经文、律法和宗教传统，与更早的西亚历史具有联系。耶稣公开传道，后在罗马统治时期被处死。基督徒相信耶稣复活，并将其视为拯救信仰的核心。

早期门徒和使徒将信仰传播到地中海城市。保罗的旅行和书信是研究早期教会的重要材料。最初的基督徒不是一个拥有独立领土、国王和军队的国家，而是分散在城市与家宅中的宗教社群。

罗马道路、港口、城市网络和希腊语、拉丁语交流环境，在客观上帮助这套宗教跨地区传播。与此同时，基督徒对传统神明崇拜的态度，也可能引起地方社会和帝国权力的冲突。

宗教信仰命题和历史研究需要区分：耶稣、保罗及早期教会的历史可以通过文献研究；复活和神迹则属于不同传统的神学信仰。

## 第三章：为什么罗马主教后来成了教宗？

罗马是罗马帝国最重要的城市之一。基督教传统认为，使徒彼得曾来到罗马并在这里殉道，保罗也与罗马有密切关系。罗马教会逐渐把这种使徒记忆视为自身地位的重要依据。

随着基督教组织发展，地方社群出现主教、长老、执事等不同职责。罗马主教的权威历经多个世纪逐渐扩大，并非耶稣时代就已经具备今天教宗的全部制度和权力。

公元64年尼禄时期曾发生针对罗马基督徒的著名迫害；303年戴克里先统治末期开始大规模迫害。313年君士坦丁和李锡尼的宗教政策保障基督教等信仰的合法礼拜；325年尼西亚会议成为教义形成的重要节点；380年以后尼西亚正统基督教获得特别帝国支持。

这些变化使基督教从边缘社群逐渐变成拥有较完善行政、神学与社会制度的宗教。

## 第四章：圣彼得大教堂为什么建在这里？

基督教传统将梵蒂冈山附近与彼得的殉道和墓葬联系起来。公元4世纪君士坦丁统治时期，在这一地区建设了早期圣彼得大教堂。

如今参观的圣彼得大教堂主要是16—17世纪重建的建筑，而不是整座原样保存的4世纪建筑。1506年前后开始的新教堂工程，历经不同建筑师和设计阶段；1626年正式举行奉献典礼。米开朗琪罗、布拉曼特、贝尔尼尼等艺术家与其建筑或周边空间密切相关。

艺术史上，梵蒂冈还有西斯廷礼拜堂、米开朗琪罗的《创世纪》天顶画和《最后的审判》、拉斐尔壁画以及大量古典艺术收藏。它们反映文艺复兴时期宗教、政治赞助与艺术创新的交织。

但必须记住：教宗资助辉煌艺术，也会引发财政、权力和道德争议；文艺复兴时期教会并非单纯的文化慈善机构。

## 第五章：教宗为什么拥有土地和军队？

西罗马帝国西部皇帝统治体系在公元476年前后瓦解，并不意味着罗马教会消失。地方主教逐渐在城市管理、救济和外交中承担更多作用。

8世纪，法兰克王权与教宗建立重要关系。通常以756年的丕平献土视作教宗国形成的重要节点。此后，教宗作为天主教领导者，同时又是意大利中部领土政权的统治者。

这导致两种不同的权力重叠：**宗教权威**与**世俗领土统治权**。

中世纪教宗与神圣罗马皇帝、意大利城市、贵族家族之间常围绕主教任命、封地和政治合法性争执。11—12世纪的叙任权斗争就是例子。

摩纳哥格里马尔迪家族卷入的圭尔夫派与吉伯林派争斗，也处于这一教宗与皇帝政治竞争的大背景中。不能把这些派别简化成两个信仰完全不同的宗教团体。

## 第六章：教会有没有发生分裂？

有，而且不止一次。

东方与西方教会逐渐在语言、礼仪、政治和教宗权威观念上产生差异。1054年常被用作东西教会分裂的象征性节点，但实际分离是长时期过程。今天东正教和天主教拥有共同的早期基督教根源，又有明显不同的组织制度。

1309—1377年，教廷长期驻于法国阿维尼翁，反映法国王权与教宗政治的密切关系。

1378—1417年，西方教会经历多个教宗竞争的严重分裂，后来通过宗教会议与政治协商逐渐解决。

1517年前后路德的批评引发宗教改革，随后产生多种新教传统。对赎罪券、教会财富和权威的争论，与神学问题及欧洲政治社会变化密切相关。天主教内部也经历反宗教改革及特伦托会议（1545—1563年）等重要调整。

因此，“基督教”不等于“罗马天主教全部教派”，也不能把所有欧洲基督徒视为受教宗直接政治统治。

## 第七章：科学、思想和教会之间只有冲突吗？

不能这样概括。教会机构在欧洲教育、手稿保存、天文学、音乐及艺术方面长期扮演复杂角色，也曾围绕特定学说发生严重审判。

伽利略的案例体现教会权威、经文解释、当时自然哲学和政治环境的冲突。但不能据此断言全部基督徒一直反对科学，也不能据教会曾支持教育就抹去历史上的压制行为。

需要把不同时代的具体人物、机构和制度分开讨论。

## 第八章：1870年为什么发生“罗马问题”？

19世纪意大利统一运动试图把各地王国、公国和教宗国合并为统一国家。

1861年意大利王国成立。1870年，意大利军队进入罗马，教宗国的世俗领土基本失去。教宗不承认新安排，教廷与意大利政府之间长期存在领土、主权与政治地位争议。这被称为**罗马问题**。

与同时期圣马力诺得以保留独立不同，教宗国绝大部分领地未能继续作为独立政权存在。

## 第九章：1929年，为什么成立梵蒂冈城国？

1929年2月11日，教宗庇护十一世代表的教廷与墨索里尼领导下的意大利政府签订《拉特兰条约》等协议。

条约确认梵蒂冈城国的独立地位，解决罗马问题，并为教廷与意大利之间的关系确立新框架。

为什么面积只有约0.44平方公里？

因为目标并不是恢复中世纪拥有大片农田和城市的教宗国，而是建立足以保障教廷独立运作的领土基础。

此处应当区分：1929年建立的是**梵蒂冈城国**，但教廷作为宗教与国际法律实体，其历史和国际联系早已存在。

## 第十章：第二次世界大战与冷战时期

二战期间，教宗庇护十二世及梵蒂冈在轴心国、盟军、罗马犹太人遭迫害等问题上的外交与行动，长期存在研究和道德评价争议。既有教会机构和信徒参与庇护受害者的事例，也有关于最高领导层公开抗议力度和实际决策的争论。应重视档案、具体行动与不同受害群体的经历，而不是一概美化或全盘否定。

战后，天主教面对去殖民化、冷战、科技发展和社会变迁。1962—1965年的第二次梵蒂冈大公会议推动礼仪、教会与现代世界关系及宗教对话方面的改革。

1978年开始的若望保禄二世教宗任期，与冷战末期、波兰社会运动以及国际宗教外交关系密切。1981年他在圣彼得广场遭遇枪击并幸存。

2013年，本笃十六世退位，使现代教宗更替制度成为全球关注焦点。教宗选举通常由枢机选举人于秘密会议中进行，并不是由全世界天主教徒全民直选。

## 第十一章：21世纪梵蒂冈有哪些真实问题？

**宗教治理**：全球不同地区的天主教会面对不同文化与社会条件，需要处理教义、地方实践和跨文化关系。

**性侵与权力滥用**：涉及神职人员侵害、机构掩盖、受害者保护和赔偿的重大丑闻，促使教会及国家司法体系加强问责。不能把它们当作宗教机构的次要声誉问题，而是具体的人权、刑事司法和治理问题。

**财政与透明度**：梵蒂冈的金融、房地产、慈善与行政运作持续需要制度改革和外部信任。

**国际外交**：教廷与大量国家保持外交关系，参与和平、人道、宗教自由、气候和社会问题的讨论；但其国际影响力来源与普通军事大国不同。

**文物与旅游**：大量游客带来文化传播机会，也增加古迹维护、环境和公共服务压力。

## 第十二章：它的文化历史到底多长？

- 罗马及梵蒂冈区域的古代人类活动早于基督教；具体“这块领土的人类历史起算年”不能仅凭教堂年代给出。
- 基督教诞生于公元1世纪，约有两千年宗教发展史。
- 罗马教宗制度经过多个世纪逐步形成，没有一个无争议的“现代教宗制度元年”。
- 教宗国作为世俗政权的传统可追溯到8世纪左右。
- 梵蒂冈城国的现代领土国家史从1929年起算，到2026年为97年。

**结论：不能把1929年、756年、彼得殉道传统和罗马城的古代史相加成某个“总文化年龄”。** 它们回答不同的历史问题。
