## 项目目标与阅读原则

对195个对象按**总面积从小到大**依次研究，一次只讲一个国家。**文化历史优先于现代建国日期**：

- 从当地最早可考的人类活动、史前迁徙和定居讲起，解释语言、宗教、亲族、食物、工艺和社会组织。
- 说明王朝、帝国、殖民、战争、现代政治经济与地方文化之间的真实因果关系，覆盖近现代与当代。
- 解释初学者不了解的术语及前置概念，重点解决“是什么、为什么、与先前历史有什么关系”。
- 文化史年数按证据分层，不把传说、考古、王朝史和主权独立年份混成单一年龄。
- B站视频为补充理解材料，提供经核查的资源或标注未核实搜索链接；新发生的事实应查最新可靠来源。

**排序口径与例外：** 195国为联合国193个会员国加教廷／梵蒂冈与巴勒斯坦国。按联合国统计年鉴为主的**总面积（陆地加内陆水域）**固定排序；与某些纯陆地面积榜单不同，不因此改变已完成国的编号。完整数据来源和边界说明见 [COUNTRY_INDEX.md](COUNTRY_INDEX.md)。

## 一次更新一个国家：应同时交付什么？

用户请求“继续”后，新会话应该：

1. 真正读取仓库进度并确定唯一下一国；
2. 进行充分历史核验、讲解该国完整文化史，避免只输出百科式几段话；
3. 将成稿保存到 `countries/NNN-english-slug/README.md`；
4. 同步更新 `data/countries.json`、`COUNTRY_INDEX.md`、`progress.json` 和本页进度；
5. 运行或检查 `scripts/validate.py`；
6. **确认GitHub真实提交后**，向用户提供该国的真实链接和新进度。

如果受限无法写入，应在回答里清楚说明，不得把未归档内容计为完成。具体请遵循 [WORKFLOW.md](WORKFLOW.md)。
