# 世界195国文化文明史

以**国土面积由小到大**为顺序，一次研究一个国家，不以现代建国日期代替所在土地的文化历史。既讲史前和古代文化，也讲宗教、制度、殖民、战争、经济和当代社会，优先解释历史机制与不同地区的联系。

## 内容与引用约定

- 不把地质年代、史前人类活动、农业聚落、文化传统、王朝更替、主权独立混为一谈。
- 以考古证据、学术文献、国家及国际机构正式资料优先；口头传说注明其性质。
- 本文所述“截至2026年”系整理时点，不自动代表后来实时状态。
- B站视频是辅助理解材料，剧情化标题、人物轶事和财富排名需要单独核验。
- 原聊天中的图片检索、地图组件、实时数据卡片和内部引文编号不适合直接进入GitHub Markdown，因此替换为文字地理说明及可阅读的资料网站和视频链接。
